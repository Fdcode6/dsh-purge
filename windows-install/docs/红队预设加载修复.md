# 红队预设加载失败兼容修复

适用：Harness 0.2.1-rc.2，dsh-purge 1.1.71；状态文件报告 toolFilter is no longer supported。

宿主的新子智能体接口要求使用独立 Agent Preset。修复在注册时迁移原有标准 deny 列表，先声明 redteam-worker 叶子预设，再声明 redteam 主预设。叶子预设不装载子智能体、工作流及循环委派工具，主预设保留 maxDepth: 1。自定义 filter 不能匹配已知结构时停止，避免放宽限制。原 YAML 和用户配置保留。

新安装由菜单 4 自动应用。已安装环境请完全退出 Harness，然后执行：

```powershell
py -3.13 .\windows-install\scripts\fix_preset.py "$env:USERPROFILE\.dsh"
```

自定义 DSH_HOME 请替换路径。脚本会备份变更文件，可重复执行。

重启后查看 DSH_HOME/redteam/preset-declare.json，期望 ok=true、phase=registered、broken=null。再检查模式界面，普通无网络任务仍需实际验证。本机实际重启验证结果见下节；另一台机器仍须独立验收。

回滚：完全退出 Harness，将 index.js.backup-* 恢复为 index.js，再重启；辅助模块在未被引用时不会生效。不要删除整个 profile 或凭据文件。
